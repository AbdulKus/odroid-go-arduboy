# Аппаратная платформа ODROID-GO и архитектура прошивки

Документ содержит техническое описание аппаратной части портативной консоли **Hardkernel ODROID-GO**, схему подключения периферии к микроконтроллеру ESP32, конфигурацию шин и обзор используемых библиотек в прошивке **Arduboy Go**.

---

## 1. Спецификация оригинального Hardkernel ODROID-GO

Портативная игровая приставка ODROID-GO была выпущена компанией Hardkernel в честь 10-летнего юбилея проекта ODROID. Консоль представляет собой набор для сборки на базе однокристального модуля **ESP32-WROVER**.

| Узел / Компонент | Характеристики |
| --- | --- |
| **Вычислительный модуль** | Espressif ESP32-WROVER (двухъядерный процессор Xtensa LX6, тактовая частота 80–240 МГц; прошивка работает на **240 МГц**) |
| **Память Flash** | 16 МиБ SPI flash. В сборке DIO, 40 МГц |
| **Оперативная память (PSRAM)** | 4 МиБ PSRAM. В сборке 40 МГц |
| **Внутренняя память SRAM** | 520 КиБ встроенной SRAM ESP32 |
| **Дисплей** | Цветной TFT LCD диагональю 2.4", разрешение 320×240 точек, контроллер **ILI9341** |
| **Аккумулятор** | Литий-полимерный (Li-Po), 3.7 В, 1200 мА·ч |
| **Питание и зарядка** | Micro-USB порт, встроенный контроллер заряда с током до 500 мА |
| **Интерфейс USB-UART** | Мост Silicon Labs CP2104 (прошивка и отладочный вывод логов) |
| **Аудиосистема** | Встроенный динамик 0.5 Вт (8 Ом), моно-усилитель PAM8304A, звук выводится через встроенный 8-битный ЦАП ESP32 |
| **Хранилище** | Слот для карт microSD (FAT32 для этой прошивки), интерфейс SPI (SDSPI) на частоте 20 МГц |
| **Беспроводные модули** | Wi-Fi 802.11 b/g/n (2.4 ГГц) и Bluetooth 4.2 BR/EDR + BLE (физически присутствуют в чипе ESP32, в прошивке отключены для экономии энергии) |
| **Разъём расширения** | 10-контактный разъём с логическими уровнями 3.3 В (порты GPIO, I²C и IRQ) |

## 2. Распиновка и подключение периферии (Pinout & Wiring)

Вся периферия консоли управляется микроконтроллером ESP32. Шина **SPI2** разделяется между контроллером дисплея ILI9341 и картой памяти MicroSD с раздельными линиями Chip Select.

### 2.1. Дисплей (ILI9341 2.4" 320×240)

* **Шина SPI**: `SPI2_HOST`
* **MOSI**: `GPIO 23`
* **MISO**: `GPIO 19`
* **SCLK**: `GPIO 18`
* **CS (Chip Select)**: `GPIO 5`
* **DC (Data / Command)**: `GPIO 21`
* **Подсветка (Backlight PWM)**: `GPIO 14`

Управление подсветкой осуществляется через аппаратный ШИМ-модуль ESP32 (`LEDC`, таймер 0, частота 12 кГц, разрядность 10 бит). Для естественного восприятия глазом применяется квадратичная кривая яркости:
$$\text{duty} = \frac{\text{percent}^2 \times 1023 + 9999}{10000}$$

Обмен данными с дисплеем выполняется на частоте **40 МГц** в полудуплексном режиме с использованием очередей транзакций DMA (`SPI_DMA_CH_AUTO`). Кадр выводится полосами по 12 строк (`StripRows = 12`) из буфера в DMA-памяти с байт-свопом (`__builtin_bswap16`), что позволяет фоновым задачам FreeRTOS (эмуляция и аудио) выполняться параллельно с передачей пикселей по SPI.

### 2.2. Слот карты памяти MicroSD (SDSPI)

* **Интерфейс**: SDSPI (драйвер `esp_vfs_fat_sdspi_mount`)
* **CS (Chip Select)**: `GPIO 22`
* **MOSI / MISO / SCLK**: разделяет шину `SPI2_HOST` (`GPIO 23`, `GPIO 19`, `GPIO 18`)
* **Частота шины**: 20 МГц (`SDMMC_FREQ_DEFAULT`)

> [!NOTE]
> В оригинальной ESP-IDF v5.4.3 совместная работа дисплея и SDSPI на одной шине требует специального исправления арбитража шины. В проект включён патч `tools/idf-sdspi.patch`, адаптированный из наработок [Retro-Go](https://github.com/ducalex/retro-go).

### 2.3. Звуковой тракт (Audio)

* **ЦАП (DAC)**: `GPIO 26` (встроенный цифро-аналоговый преобразователь ESP32, DAC Channel 1 / DAC2)
* **Включение усилителя (Speaker Enable)**: `GPIO 25` (линия /SD усилителя PAM8304A)
* **Частота дискретизации**: 32 000 Гц (`DacHz = 32000`)
* **Буферизация**: кольцевой потоковый буфер FreeRTOS `StreamBuffer` объёмом 2048 байт и непрерывный режим DMA (`dac_continuous_write_asynchronously`)

Линия `GPIO 25` удерживается в низком уровне вне игры и при нулевой громкости и активируется только во время воспроизведения аудио.

### 2.4. Органы управления (D-Pad и кнопки)

Управление ODROID-GO сочетает цифровые входы и аналоговую схему для крестовины:

#### Аналоговая крестовина (D-Pad)
Для экономии выводов ESP32 крестовина подключена к встроенному АЦП через резистивные цепочки делителя:
* **X-Axis (Влево / Вправо)**: `ADC1_CHANNEL_6` (`GPIO 34`)
* **Y-Axis (Вверх / Вниз)**: `ADC1_CHANNEL_7` (`GPIO 35`)

Пороговые значения АЦП для осей:
* Значение $\ge 3072$ (с гистерезисом 2940) — направления **Left** или **Up**.
* Значение $\ge 1024$ (с гистерезисом 900) — направления **Right** или **Down**.
* Реализован программный фильтр антидребезга длительностью 7 мс перед фиксацией стабильного нажатия.

#### Цифровые кнопки
* **Кнопка A**: `GPIO 32` (внутренняя подтяжка к 3.3 В, активный уровень LOW)
* **Кнопка B**: `GPIO 33` (внутренняя подтяжка к 3.3 В, активный уровень LOW)
* **Кнопка Menu**: `GPIO 13` (внутренняя подтяжка к 3.3 В, активный уровень LOW)
* **Кнопка Select**: `GPIO 27` (внутренняя подтяжка к 3.3 В, активный уровень LOW)
* **Кнопка Start**: `GPIO 39` (линия ввода без внутренней подтяжки ESP32, внешняя схема)
* **Кнопка Volume**: `GPIO 0` (BOOT-пин, внешняя схема)

### 2.5. Мониторинг аккумулятора

* **Канал АЦП**: `ADC1_CHANNEL_0` (`GPIO 36` / `SENSOR_VP`)
* Напряжение батареи поступает через резистивный делитель 1:2.
* Чтение использует калибровку ESP32 Line Fitting (`adc_cali_raw_to_voltage`) с опорным напряжением 1100 мВ и аттенюацией 12 дБ (`ADC_ATTEN_DB_12`).
* Процент заряда рассчитывается усреднением 8 выборок в диапазоне напряжений 3.5 В (0%) — 4.2 В (100%):
$$\text{Level}_{\%} = \operatorname{clamp}\left(\frac{2 \times U_{\text{mV}} - 3500}{7}, 0, 100\right)$$

### 2.6. Разъём расширения (10-pin Expansion Header)

Разъём расширения рассчитан на логику 3,3 В. Прошивка не выделяет на нём дополнительные функции. [Спецификация ODROID-GO](https://github.com/hardkernel/ODROID-GO#specifications)

## 3. Сторонние библиотеки и интеграция

В прошивке задействованы легковесные библиотеки, скомпилированные непосредственно в составе проекта без внешних зависимостей:

| Библиотека / Модуль | Назначение в Arduboy Go | Лицензия |
| --- | --- | --- |
| **[Ardens](https://github.com/tiberiusbrown/Ardens)** (ревизия `e811cc6`) | Ядро эмуляции микроконтроллера ATmega32U4 (16 МГц), OLED SSD1306 (128×64), звукового таймера Timer3 и микросхемы SPI Flash W25Q128 (Arduboy FX). Таблицы инструкций выделяются в PSRAM. Горячее состояние AVR по возможности хранится во внутренней RAM. Сборка не включает LLVM и профилировщик. | MIT |
| **[Cathy3K Bootloader](https://github.com/MrBlinky/Arduboy-homemade-package)** | Унаследованные от Ardens исходники загрузчика и встроенные данные FX. Arduboy Go запускает ROM напрямую. | MIT |
| **[Bitsery](https://github.com/fraillt/bitsery)** & **[LZAV](https://github.com/avaneev/lzav)** | Bitsery сериализует состояние слота. LZAV входит в исходники Ardens для истории отладчика. | MIT |
| **[yyjson](https://github.com/ibireme/yyjson)** | Парсер JSON для извлечения метаданных из файла `info.json` внутри `.arduboy` архивов. | MIT |
| **[miniz](https://github.com/richgel999/miniz)** (ревизия `ae07a36`) | Чтение ZIP-архивов пакетов `.arduboy` без их предварительной распаковки на MicroSD-карту, расчет CRC32 для целостности сохранений и каталога. | MIT / Zlib |
| **[LodePNG](https://github.com/lvandeve/lodepng)** (ревизия `7b2893e`) | Декодирование PNG-изображений обложек и баннеров в RGB565 для отображения карточек в библиотеке. | Zlib |
| **Шрифт Liberation Sans** | Растеризованные растровые глифы (включая латиницу и кириллицу `U+0400`–`U+045F`), сгенерированные скриптом `tools/make-font.py`. | SIL OFL 1.1 |
